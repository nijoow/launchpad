# 실제 휴대폰에서 박자 판정 비교하기

## 측정

1. 같은 사람이 같은 휴대폰과 브라우저로 미리보기의 `/timing-test`를 연다. 휴대폰 기종과 브라우저 버전을 입력한다. 가능하면 iOS Safari와 Android Chrome에서 각각 별도 파일을 만든다.
2. 한 번 연습한 뒤 새 탭에서 본 측정을 시작한다. 볼륨과 자세를 일정하게 유지하고, 실제 연결된 출력을 고른다. 출력 선택은 기록용이다. 이어폰 연결과 해제는 휴대폰에서 한다.
3. 내장 스피커 → 블루투스 이어폰을 세 번 반복한다. 매번 같은 〈환희의 송가〉 4마디를 반주에 맞춰 터치한다. 완주 후 기억이 생생할 때 체감을 적는다. 중단한 회차는 재시작하며 완주 횟수에 포함되지 않는다.
4. 탭을 닫기 전에 결과 JSON을 내려받는다. 같은 기기와 브라우저에서 출력별 완주 횟수, 음표 순서 불일치 횟수, 실제 게임의 정확·성공 수를 함께 본다.

## 판독과 결정

각 입력은 게임의 오디오 시계에서 첫 박자 기준 ms로 기록한다. 악보의 15개 음과 순서가 일치한 회차만 해당 음의 목표 시각을 빼서 비교한다. 음수는 일찍 누름, 양수는 늦게 누름이다. 게임이 놓침으로 처리한 입력도 분포에 포함한다. 추가 입력·누락·다른 음이 있는 회차는 잘못 짝짓지 않도록 원본만 보존한다. 제외된 회차가 한 출력에 몰리면 남은 회차의 중앙값만으로 결론을 내릴 수 없다.

회차마다 중앙값과 가운데 절반(P25–P75), 실제 게임의 ±75 ms 정확·±150 ms 성공 판정, 사용자 체감을 나란히 본다. 같은 출력의 회차 간 흔들림에 비해 출력 변경 시 한 방향의 이동이 반복되고 판정과 체감도 나빠지면 출력별 보정 실험을 진행한다. 반복 측정에서 차이가 작고 판정과 체감이 유지되면 현행 판정을 유지한다. 결과가 엇갈리면 같은 조건에서 순서를 바꿔 다시 측정한다. 여기서 측정하는 값에는 오디오 출력, 터치 처리, 연주자의 반응이 함께 들어 있다.

현재 실기기 측정값은 미수집 상태이며 보정 도입 결정은 보류한다.
