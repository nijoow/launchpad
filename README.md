# Nijoow Launchpad

피아노와 드럼을 연주하고, 4마디 루프를 녹음해 내 기기에 저장하는 웹 악기입니다.

## 기능

- 드럼 9개 패드, 피아노 36개 패드(C3–B5)
- 키보드·마우스·멀티터치 입력과 눌림 표시
- 볼륨, 음 이름·단축키 표시 설정 및 설정 복원
- BPM 60–180, 1마디 카운트인, 4마디 녹음과 자동 반복 재생
- 녹음·재생 중 메트로놈, 16분음표 박자 보정 옵션
- 루프 이름 변경, 기기 내 저장·불러오기·삭제, 마지막 저장 루프 자동 복원

## 실행

Node.js 24과 Yarn 4.3.1을 사용합니다. 별도의 환경 변수나 백엔드가 필요하지 않습니다.

```sh
corepack enable
yarn install
yarn dev
```

기본 주소는 `http://localhost:3000`입니다. Corepack을 사용할 수 없다면 저장소의 `node .yarn/releases/yarn-4.3.1.cjs`로 Yarn 명령을 실행할 수 있습니다.

## 사용법

1. Drum 또는 Piano를 선택하고 패드를 누르거나 표시된 키로 연주합니다. 한글 입력 상태에서도 물리 키 위치를 기준으로 동작합니다.
2. BPM과 박자 보정을 설정하고 녹음을 누릅니다. 네 박자를 센 뒤 4마디 동안 연주합니다.
3. 녹음이 끝나면 자동으로 반복 재생합니다. 정지 후 재생하거나 다시 녹음할 수 있습니다.
4. 루프 이름을 입력하고 저장합니다. 저장한 루프 목록에서 다시 열거나 삭제할 수 있습니다.

드럼은 숫자열과 텐키의 1~9 키를 모두 지원합니다. 텐키는 Num Lock이 꺼져 있어도 같은 위치의 패드를 재생합니다.

한 루프에 Drum과 Piano 레이어를 함께 사용합니다. 악기를 바꿔도 기존 음표는 유지됩니다. 재생 중 추가 연주는 녹음에 합쳐지지 않습니다. 다시 녹음은 선택한 악기 레이어만 교체하고 다른 레이어를 반주로 재생하며, 저장 버튼을 누르기 전에는 이전 저장본이 유지됩니다. 카운트인은 메트로놈 옵션과 별개로 항상 들립니다.

프로젝트는 IndexedDB에, 표시 설정과 마지막 열었던 프로젝트 ID는 localStorage에 저장합니다. 저장하지 않은 작업은 새로고침 시 사라질 수 있고, 브라우저 데이터를 지우면 저장본도 삭제됩니다. 다른 브라우저·기기와는 동기화하지 않습니다. 다른 탭이나 앱으로 이동하면 재생을 중지합니다.

## 검사

```sh
yarn lint
yarn typecheck
yarn test
yarn build
```

자동 테스트는 샘플 캐시·자원 정리, 첫 재생 취소, 키보드 매핑, 녹음 구간·박자 보정, 루프 예약, 저장 데이터 검증, IndexedDB 저장·삭제·트랜잭션 취소를 확인합니다. IndexedDB 테스트는 `fake-indexeddb`를 사용합니다.

브라우저 확인 항목은 녹음 → 자동 반복 → 정지 → 저장 → 새로고침 복원, 키 자동 반복·modifier·텍스트 입력 차단, 동시 입력·입력 취소, 모바일 hydration과 가로 넘침입니다. 실제 iOS Safari·Android Chrome에서 오디오 시작, 지연감, 멀티터치를 추가 확인해야 합니다.

## 레이어 편집과 내보내기

- 모바일에서는 **소리 시작**을 먼저 누른 뒤 연주합니다. 샘플은 미리 불러오며, 준비된 연주 경로는 오디오 시계에 즉시 예약합니다.
- 악기 탭에 각 레이어의 음표 수가 표시됩니다. **루프 편집**에서 패드를 선택하고 4마디 × 16칸을 눌러 추가·삭제합니다. 기존 비보정 음표는 같은 칸을 지우기 전까지 원래 시각을 유지합니다.
- **선택 레이어 비우기**와 **되돌리기**로 최근 편집·녹음을 한 번 취소할 수 있습니다. 바뀐 루프는 저장을 눌러야 보관됩니다.
- **WAV 내보내기**는 현재 볼륨으로 두 레이어를 44.1kHz/16bit/stereo WAV 한 루프에 담습니다. 메트로놈은 제외하고, 잔향을 루프 시작으로 감아 경계를 연결하며 디지털 클리핑을 방지합니다.
- **공유 링크 만들기**를 누를 때만 음표와 BPM을 URL fragment에 넣습니다. 이름·ID·설정·개인정보·오디오 파일을 업로드하지 않으며 새 백엔드가 없습니다. 수신자는 **공유 루프 열기**를 눌러야 작업을 교체하고, 저장 시 새 ID를 받습니다.
- 링크를 가진 사람은 내용을 읽고 재공유할 수 있습니다. 링크는 암호화되지 않으며 메신저 등 전달한 서비스에도 보일 수 있습니다. 최대 16,000자이며, 긴 루프는 음을 줄이거나 WAV로 전달합니다. 링크는 생성 시점의 스냅샷입니다.
- v1 저장본을 계속 읽고 새 저장본은 v2로 기록합니다. 구버전 앱은 v2 저장본을 표시하지 못합니다.
